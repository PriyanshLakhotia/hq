# HQ

A personal MCP headquarters for working and learning while biking: lists,
quick capture, study cards, ride briefings, and Amp coding threads.

Built for remote MCP clients with OAuth at `/mcp`. Voice availability depends
on the ChatGPT plan and client; see [the product direction](docs/VISION.md).

Implementation and deployment instructions are being added in staged commits.
Brightspace is intentionally deferred. Real credentials and personal data must
stay outside this public repository.
